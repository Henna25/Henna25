# 👋 Hi, I'm Fathimathul Hennath P.H.

**Ocean modeller who seeks to work on the improvement of ocean forecasting using machine learning and numerical modelling**

I am a Master's graduate in Oceanography specialising in **numerical ocean modelling (ROMS, MOM6)**, **climate data analysis**, and **hybrid machine learning architectures (BCNN, LSTM-VMD)** for ocean-atmosphere forecasting.

### 🔬 Current Research Focus
* **IISc Bengaluru (CAOS) / NPOL Collaboration:** Evaluating vertical temperature and salinity structures in the Indian Ocean using **ROMS** and **MOM6** with advanced mixing schemes.
* **Master's Thesis Research (INCOIS):** Applied Bayesian Convolutional Neural Networks (BCNN) for ENSO prediction and a hybrid LSTM-VMD model for short- and long-term Sea Surface Salinity forecasting.
